# Crypto Commerce UI

`TypeScript + React + Next.js + Tailwind CSS`로 다시 구성한 쇼핑몰 UI 테스트 프로젝트입니다.

## Included

- App Router 기반 Next.js 구조
- 실시간 USDT/KRW 참고 환율 표시
- 상품 캐러셀
- 특가 더보기 토글
- FAQ, 결제 안내, 정책 섹션

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

이 프로젝트는 Vercel 배포를 기준으로 구성했습니다.
